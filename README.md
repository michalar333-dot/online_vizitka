Online vizitka pro Advokátní kancelář Matzner & Vítek.

- `index.html` – samotná stránka (CZ/EN přepínač, sdílení odkazu)
- `viktorie-tesarova.vcf` – kontakt pro tlačítko „Uložit do kontaktů“
- `viktorie-tesarova.jpg` – portrét
- `qr-vizitka.png`, `qr-vizitka.svg` – QR kód na online vizitku (SVG pro tisk)

Stránka běží přes GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
